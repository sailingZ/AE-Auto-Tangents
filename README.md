# AE动画曲线切线脚本

适用于 Adobe After Effects 2023 的自动相切 3.0 脚本。

## 下载与使用

- 下载 AE-Auto-Tangents-2023-v3.zip 并解压。
- 在 AE 中选择：文件 → 脚本 → 运行脚本文件，打开 AutoTangents2023.jsx。
- 选中至少两个相邻关键帧，再点击面板中的功能按钮。
- 详细安装方法、适用范围和限制见 [使用说明](使用说明.txt)。

## 功能

- 自动相切：经典、固定斜率
- 独立移除超调
- 加权相切及一次性自动加权
